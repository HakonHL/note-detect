# note-detect

A C and Python-based project for musical note detection.

## Overview

This project provides tools for detecting and analyzing musical notes from audio signals. Built with C for performance-critical components and Python for ease of use and scripting.

## Technologies

- **C** (75.4%) - Core signal processing and detection algorithms
- **Python** (24.2%) - High-level interfaces and utilities
